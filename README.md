# YouTube Downloader (Python + yt-dlp)

A simple and powerful desktop YouTube downloader built using Python and yt-dlp.  
This application allows users to download videos or extract audio directly from YouTube with FFmpeg integration.

---

##  Features

- Download YouTube videos in best available quality
- Extract audio (MP3)
- Automatic video + audio merging using FFmpeg
- Clean desktop GUI built with Tkinter
- Real-time download progress
- Error handling and status updates

---

##  Tech Stack

- Python
- yt-dlp
- Tkinter
- FFmpeg

---

##  Installation

### 1. Clone the repository

```bash
git clone https://github.com/Alan835217/YoutubeVideo_Downloader.git
cd YoutubeVideo_Downloader
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Install FFmpeg

Download FFmpeg and add it to your system PATH.

If installed manually, update the FFmpeg path inside `app.py` if needed.

### 4. Run the application

```bash
python app.py
```
